# Interface direction

Source: the user's example-image.png. Dark warm charcoal surfaces, a compact sidebar, large storage total, colored category icons, a segmented storage bar, and a floating selection bar. System typography preserves the macOS utility character. Category colors encode the same categories across navigation, storage segments, and results. Blue is reserved for the primary action. Stripes mean unselected data; solid fill means selected data.

Energy 2, rhythm 2, motion 1: the storage total is the overview focal point; results become the focal point in category views. Cards group the actual cleanup categories from the plan. Transitions only acknowledge hover, focus, and progress. The native macOS title bar supplies real window controls.

All displayed storage values come from scans. The browser preview uses an honest empty state; sample data exists only in automated UI tests. Nothing is preselected, including caches. Both light and dark appearance are supported, with system appearance as the default.
